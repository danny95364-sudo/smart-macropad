# CYD 多益背單字 計畫書

## 目標
考多益約 700 分。CYD 放眼角，被動瞄＋快捷鍵盤一鍵回答「會／不會」，零摩擦地背 TOEIC 單字。
**需求導向試用**：先用一段時間，效果不好就改回原本的快捷鍵功能。

## 已定案
- **完全無聲**：沒有發音、按鍵音、提示音。
- **架構 B（電腦為主）**：字表、進度、排程都在電腦；CYD 只負責顯示＋觸控回報。時間用電腦的，不需要 Wi-Fi。
- **鍵盤分工**（2026-11-08 統一）：鍵 1、2、旋鈕給背單字；鍵 3～6 維持原本工作快捷鍵。背單字整合進 macropad 常駐程式，**由同一個程式註冊全部 9 組熱鍵**，不與其他程式搶；任何一組註冊失敗就在啟動時明確報錯並停止，不悄悄失效。
- **字表**：先 TOEIC Service List（TSL 1.2，1,200 字），之後視需要補 NGSL 2,809 字中不熟的字。兩者皆 CC BY-SA 4.0，須在檔案內註明出處與授權。
- **輪播為主**：輪播池約 25 字自動輪播（正面英文 6 秒 → 背面中文 8 秒，秒數可調）。按旋鈕可立即翻面（主動背時自己控節奏）。
- ~~背起來了 → 3 天、10 天兩次抽查~~（2026-11-08 改用 FSRS，見下方「學習演算法 v2」）。
- **輪播池盡量不縮小**：目標 25 張，空位由新字補；但受每日新字上限約束，畢業多於新字時池會暫時變小（可接受，見「排程細節」）。
- **順序**：新字依 TSL 頻率順序加入；池內隨機打散；同主題、形近字（adapt/adopt）避免連續出現。
- **方向**：英→中（認得即可，對應多益）。

### 研究依據（2026-11-08 查）
- 主動回想優於重看；先出英文讓人自己想，再出中文。
- Kornell & Bjork 2008：答對一次就丟掉字卡會學得較少 → 學習中要兩個不同日子都答會才畢業，畢業後仍由 FSRS 持續複習。
- Kornell 2009：一疊 20 張優於 4 疊 5 張（90% 受試者），但 72% 的人主觀偏好小疊 → 不縮池。
- Tinkham 1993 / Waring 1997：語意相近的字放同組會互相干擾（後續研究結果分歧）→ 打散。
- Cepeda 2008/2009：最佳間隔約為「距考試時間」的 10～40% → v1 據此定 3 天、10 天；v2 改由 FSRS 依個人記憶曲線計算。
- Nakata 2013：延後回饋對單字沒有明顯幫助 → 秒數依手感調，不必拘泥。

## 學習演算法 v2（2026-11-08 定：使用者要「最科學的方法」）
- **排程用 FSRS**（Free Spaced Repetition Scheduler，Anki 內建的開源演算法，離線 Python 套件 `fsrs`）。每字記「穩定度、難度、上次複習時間」，算出現在還記得的機率；機率降到目標保留率 **90%** 就到期。取代寫死的 3 天、10 天。
- **評分只有兩級**：會（Good）／不會（Again）。FSRS 支援二元評分，按鍵最少。
- **沒看到 ≠ 不會**：被動輪播時沒按任何鍵 = 沒作答，**不評分、不影響排程**。只有明確按「不會」才算忘記。避免把「沒抬頭看」記成「不會」而污染資料。
- **字的狀態**：未學 → 學習中（輪播池，被動曝光＋可作答）→ 複習中（FSRS 排程，到期才出現）。複習中按「不會」→ 回學習中。沒有「已掌握」終點，間隔自然越拉越長。
- **到期複習卡要作答**：只顯示英文、**不自動翻面、不自動換卡**，等使用者翻面後按會／不會（主動回想＋立即回饋）。放著不理超過一輪就先跳過，稍後再出，仍不評分。
- **缺課、週末**：FSRS 用實際經過的時間計算，停幾天回來時，記得機率已經變低的字自然先到期。積壓時每天複習上限 **30 張**，依「記得機率最低」優先；有積壓的日子不加新字。
- **新字**：照 TSL 頻率順序，輪播池有空位才補，每日上限 10 個（考試日期定了再調）。
- **流水號**：「D12·新3」。D = 有開背單字的日子序號（以換日時間切日），k = 當天第幾個新字；複習卡改標「複習」。

### 評分規則（審查補強）
- **Easy**：只限「第一次出現、還沒顯示過背面」時按會（隨出隨篩）。
- **Good**：其他情況按會（包括學習中已看過背面的字、到期卡翻面後按會）。
- **Again**：按不會。
- 學習中按「會」是**畢業進度**，不是直接畢業：需在**兩個不同的日子**各按一次會才進複習中（第一次 FSRS 評分用 Good）。學習中按「不會」= 畢業進度歸零，字留在池中、出現頻率提高（下一輪優先）。
- 被動曝光（輪播時只顯示、沒按）不寫入 FSRS，不改變 last_review 時間。

### 排程細節（審查補強）
- **換日時間**：凌晨 4:00。D、每日上限都在這時重算；程式整夜沒關也照這個切日。
- **每日複習上限 30**，依記得機率由低到高出題。
- **新字**：每日上限 10；「積壓」定義為**當天 30 張答完後仍有到期卡**，積壓時新字降到**保底 3 個**，不會永遠停加。
- **到期卡出法**：混進輪播，每 3 張學習卡插 1 張到期卡。到期卡只顯示英文、不自動翻面；**60 秒**沒任何按鍵就跳過（不評分），稍後再出。旋鈕按下翻面後才能答；翻面前按會/不會也接受（算回想成功/失敗）。
- **誤按與反悔**：作答後 5 秒內旋鈕左轉 = 撤銷這次作答（回復 FSRS 狀態）；同一張卡 2 秒內的重複按鍵忽略。
- **鎖定／睡眠**：偵測到 Windows 鎖定或休眠就暫停輪播（不送卡、不計曝光）；解鎖後重新連序列埠再繼續。
- **字的 id**：「單字＋詞性」（例 `record|n.`、`record|v.`）；字表更新時用 id 對應進度，找不到的進度保留不刪並記警告。
- **存檔**：progress.json 存每字的 FSRS 卡片狀態（stability、difficulty、due、last_review、state）＋畢業進度；另存作答紀錄 `vocab/reviews.csv`（時間、id、評分）供日後最佳化參數。寫入先寫暫存檔再改名；每天換日時備份一份 `progress-YYYYMMDD.json`，保留 14 份。
- **分類**：在家產生字表時加主題欄（辦公、財務、人事、旅行、採購…），只用於統計與篩選，不分組出題（避免同主題互相干擾）。
- **參數**：先用 FSRS 預設參數；累積約 1,000 次作答後，在家用自己的資料最佳化一次。

### 介面原則
- 先出英文、後出中文（主動回想）；到期卡由使用者決定何時翻面。
- **到期卡要一眼分得出來**：卡片左側 6px 紫色直條＋狀態列左邊「複習」色塊；學習卡無直條。
- 正面只留單字與一條狀態列，其他資訊收到背面或電腦端（減少干擾）。
- 每次作答後立刻看到正確答案（背面），按下的結果用短 toast 確認。
- 相似字、同主題不連續出現（沿用打散規則）。
- 狀態列（efontTW_14，總寬 ≤ 300px，要截圖驗證）：左「D12·新3」或「複習」色塊，右「答8·剩5」（今日已作答數 · 今日到期剩餘數）；暫停時左側加「暫停」色塊。

## 字卡內容
- 正面：英文單字（大字）。
- 背面：詞性、中文意思、一句原創短例句（≤ 1.5 行）。
- 中文與例句在**家裡**用 Claude 產生、抽查後，產出一個 `vocab/tsl.csv` 帶到公司；不抄市售單字書。

## 流程
1. ~~篩字（第一次使用跑一次）~~ → **隨出隨篩**（2026-11-08）：新字第一次出現、翻面前就按「會」= 本來就認識，以 FSRS Easy 評分直接進複習中（第一次間隔約 1～2 週），**不佔每日新字名額**，空位立刻補下一個。不另做篩字模式；自評高估（yes/no 測驗的 overclaiming）由之後的抽查抓回。
2. **日常**：輪播池約 25 字自動輪播；到期卡依「排程細節」混入，標「複習」與紫色直條。
3. **進度常駐在狀態列**：D·新字序號、今日已答、到期剩餘。

## 元件
- `macropad/vocab.py`：FSRS 排程、輪播池、送卡片給 CYD；由 macropad 常駐程式載入（鍵 1、2、旋鈕交給它，鍵 3～6 照舊）。
- `vocab/tsl.csv`：字表（英文、詞性、中文、例句）。
- `vocab/progress.json`：每字 FSRS 狀態＋畢業進度（格式見「排程細節」）；`vocab/reviews.csv` 作答紀錄；`vocab/flags.csv` 標錯清單。
- `firmware/cyd/src/vocab/`：CYD 顯示韌體（新 env `cyd_vocab`），只收顯示指令、回報觸控。中文字型：狀態列 efontTW_14、按鍵說明 12、中文意思與 toast 24（示範韌體實測可用）。
- `背單字.bat`：一鍵啟動。

## 公司電腦安全原則
1. **不連網**：電腦端程式與 CYD 都不做任何網路連線；CYD 不啟用 Wi-Fi／藍牙。字表離線帶入。
2. **不收集資料**：只記錄單字答題結果，存在本機專案資料夾；沒有遙測、沒有上傳。
3. **不攔截鍵盤**：熱鍵用 Windows `RegisterHotKey`，只登記 ctrl+alt+shift+1～9 這九組，不裝全域鍵盤鉤子（不會被當成側錄程式）。
4. **不需要管理員權限**：Python 用專案 `.venv`（uv），不裝服務、不改登錄檔、不設開機自動啟動；要用時手動點 bat。
5. **不在公司燒韌體**：韌體在家燒好；公司電腦不裝 PlatformIO。
6. **USB 裝置**：CYD 是 USB 序列埠（CH340 類晶片）。Windows 11 通常內建驅動；**若需要安裝驅動或被 USB 政策擋下，就停，先問 IT，不要自己繞過**。
7. **AI 內容在家產生**：公司電腦上不呼叫任何 AI 服務；字卡只是靜態 CSV。
8. **出問題可完全移除**：刪掉專案資料夾即可，沒有殘留。

## 實作順序
1. 家裡：產生 `vocab/tsl.csv`（含授權註記），抽查 50 字。
2. 家裡：CYD 韌體 `cyd_vocab`（卡片正反面、進度畫面、觸控回報）。
3. 家裡：`macropad/vocab.py` + 排程 + 進度存檔 + `背單字.bat`。
4. 家裡實測一天（鍵盤＋觸控＋斷電後進度還在）。
5. 公司：確認 USB 序列埠可用（不需裝驅動），再開始用。
6. 試用兩週後檢討：每天實際答了幾題、有沒有變成背景噪音。
