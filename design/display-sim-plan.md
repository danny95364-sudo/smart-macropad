# 電腦上的看板模擬視窗（取代 ESP32 CYD，等硬體到貨前用）

## 目標
常駐程式把「看板要顯示的資料」送出去，電腦上開一個 320×240 的小視窗照設計方向 **B 色塊** 畫出來。
之後 CYD 到貨，只把傳輸換成 USB 序列埠，資料格式不變。

## 決策
- 設計方向：**B 色塊**（使用者 2026-10-27 選定）。規格、九個狀態、配色都照 `design/screen-design.html` 裡「方向 B」那段（約第 254–360 行）。
- 畫面尺寸：320×240（CYD 2.8 吋橫放），視窗可切 1× / 2× 縮放，預設 2×；無邊框、置頂、可拖曳，位置記在本機。
- 技術：tkinter（標準庫，不加相依套件），字型用「Microsoft JhengHei」。
- 獨立程序：模擬視窗是另一個 process（`python -m macropad.display_sim`），常駐程式用 **localhost UDP、一行一個 JSON** 傳資料。這和之後的序列埠「一行一個 JSON」一致。
- 常駐程式這邊做一個「看板輸出」介面（例如 `display.py`），目前實作：UDP 送給模擬視窗；預留：序列埠。設定檔加 `display = "sim" | "serial" | "off"`，預設 `sim`。`sim` 時常駐程式啟動時順便把模擬視窗開起來，結束時一起關。
- 看板沒開或送失敗，常駐程式照常運作，不能當掉。

## 資料格式（之後送 CYD 也用這個，欄位名稱寫進檔案開頭註解）
- 模式切換時送 `state`：模式代號、模式名稱、模式顏色、1～6 鍵標籤、旋鈕左轉／右轉／按下標籤
- 按鍵時送 `press`：哪一顆鍵、標籤、結果文字（可為空）
- 實際欄位由實作決定，但要精簡（CYD 記憶體小），並在 README 或檔案註解寫清楚

## 限制
- 不要碰按鍵 AI 功能，不要加任何 Claude / claude -p 呼叫。
- 本機 Python 3.10 不能用；用 `uv run --python 3.12` 或 `啟動.bat` 的方式跑。
- 不要改 `keyboard-mapping.yaml`、`config.toml` 的 `[hotkeys]`。

## 完成標準
1. `啟動.bat` 雙擊後，常駐程式和模擬視窗都開起來
2. 切到記事本 / PPT / 其他視窗，看板的模式色與鍵標籤跟著變
3. 按鍵後看板顯示按下回饋與結果
4. 截圖存在 `screenshots/sim_*.png`（至少：一般模式待機、記事本模式按鍵後）
